# work-please
## SkyGen Shop

A Minecraft Bedrock shop add-on for SkyGen servers, based on mvShop v1.0.6 and updated for Minecraft 1.21.90+ (Script API 2.0.0).

- `SkyGenShop/` – behavior pack source
- `dist/SkyGenShop-v2.0.0.mcpack` – ready-to-install pack

See `SkyGenShop/Info.txt` for setup and the changelog.
